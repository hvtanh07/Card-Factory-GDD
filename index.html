Section 01

Gameplay Overview

Genre Sorting Puzzle / Stack Clear
Theme Ship & Container Logistics
Core Objective Match Goods & Pack Containers

● Goods Stack (Card Factory) is a spatial sorting puzzle game where players untangle stacked layers of colored cargo containers to completely clear the ship's deck.

● By dispatching containers to the parking slots and directing cardboard box items onto conveyor tracks, players match products with corresponding colored containers to complete shipment orders.

● The game emphasizes logical sequence planning—selecting the correct dispatch order of containers prevents parking slot congestion and conveyor jam states.

Core Gameplay Loop

Play Stage Level
Win Level ➔ Earn Coins
Advance to Next Stage
Fail Stage ➔ Revive / Retry

Victory Condition

  • The level is won when ALL CONTAINERS on the board have been fully packed and dispatched.
  • Upon victory, awards player with coin rewards based on performance.

Defeat Condition (Slot Gridlock)

  • Occurs when all open Parking Slots are occupied by incomplete containers, and the conveyor belt shelf space is completely filled.
  • If no further moves can unpack items or free a slot, a Game-Over popup appears.
REVIVE MECHANIC: Revive option triggers a FREE Wood Container Booster (Item Vacuum) to clear 8 items from the conveyor belt!
Section 02

Core Game Mechanics

1 Colored Containers & Multi-Layer Board

State A: Puzzle Board Layout

3D Stack
  • 3D Multi-Layer Layout: Containers are arranged in overlapping 3D geometric configurations (crosses, elevated platforms).
  • Occlusion & Lock System: Unblocked top containers automatically open lids to reveal contents. Blocked containers underneath cannot be tapped.
  • Selection & Transfer (Left-to-Right): Tapping an unblocked container animates it sliding into the FIRST AVAILABLE parking slot from left to right.

State B: Parking Slots & Processing

Staging Area
  • Parking Slot Staging: Buffer line with 4 default parking slots (+1 extra slot unlockable via Rewarded Ad).
  • Auto-Unpack Mechanism: When container arrives, non-matching cardboard box items fly up onto the conveyor belt track.
  • Item Matching & Completion: Items on belt matching container color fly inside. Reaching capacity seals container and frees parking slot.

Conveyor Belt Track

Stores loose cardboard box items extracted from containers. Each level specifies a strict item capacity limit on the track.

Speed-Up Feature (2x)

Toggleable 2x game speed feature. Multiplies conveyor belt scroll velocity and item/container move animations.

Wood Container Sub-Mechanic (Spare Crate)

A static wooden container placed on the puzzle board containing a pre-set stack of cardboard box items. Unlike standard color containers that remain on the board as empty frame structures, a Wood Container automatically SHATTERS AND DISAPPEARS from the board state as soon as its last item is dispatched onto the conveyor belt.

Section 03

Special Puzzle Elements

Special elements introduce sequence challenges and dynamic tactical depth to higher level stages.

🌈

Rainbow Container

Conceals true target color under a rainbow wrapper while blocked. Once fully unblocked, permanently reveals true color and acts as standard container.

🚢

Ship Door Spawner

Fixed ship portal containing queued container stack with counter UI. When exit container is dispatched, counter decrements by -1 and spawns next container.

🧊

Frozen Container

Encased in ice block with countdown value K. While unblocked, dispatching ANY other container on board decrements K by -1. Reaching 0 shatters ice.

🔒

Locked Slot

Parking slot disabled at start with countdown S. Dispatching any container to an open slot decrements S by -1. Reaching 0 removes lock into an empty slot.

Section 04

Boosters & Power-ups

📦

Booster 1: Wood Container Vacuum

Conveyor Belt Clearer & Defeat Revive Mechanism
Anti-Softlock Power
Behavior & Extraction:

Scans items on conveyor track, extracts up to 8 items, and stacks them into a newly spawned Wood Container below the conveyor (without consuming parking slots).

Sorting Priority & Conditions:

Groups items by matching color first. Requires at least 1 item on belt. Automatically prompts as FREE REVIVE option upon jam state defeat.

🧲

Booster 2: Magnet Pull

Targets Largest Parking Container
Target Biggest Parking Container

● Target Selection Logic: Automatically selects the BIGGEST container currently sitting in the Parking Slots (the container with the largest total item capacity).

Resource Acquisition Hierarchy (Fills R required items):
1. Priority 1 (Conveyor): Extract items directly from conveyor belt track & queue.
2. Priority 2 (Active Board): Extract items from unblocked containers on the board stack.
3. Priority 3 (Deep Fallback): Penetrates Blocked Containers, Rainbow Masks, Spawners & Frozen Ice layers.
🏗️

Booster 3: Crane Grabber & Swap

Board Stack Container Target Only
Board Stack Target Exclusive

● Target Constraint: Allows player to tap to select any unblocked container ONLY FROM THE PUZZLE BOARD STACK (containers in parking slots CANNOT be selected).

● Smart Cardboard Box Swapping: If target container T contains mismatched items of Color D, pulling Color C items from source container S triggers a 1-to-1 swap, transferring Color D items back to source S to conserve total level items.

Section 06

Object Set & Animation Specs

Color Palette & Tier Scheme (8 Color Set)

Both Container Cargo and Cardboard Box items share a unified 8-color scheme across all stage configurations: Red, Blue, Green, Yellow, Pink, Orange, Brown, and Cyan. Each color tier maps to distinct shape parameters and visual identifiers.

Red Blue Green Yellow Pink Orange Brown Cyan

1. Core Gameplay Objects

Container Cargo

Core Asset
  • ● 4 Size Variants: 4, 6, 8, 10 item slot capacity.
  • ● 2 Operational States: Closed (display directional arrow) & Open (revealing internal items).
ANIMATION SPEC:

1. Move: Lift & parabolic arc transition from stack to parking slot (0.35s).

2. Open Lid: Hinge lid rotates 110 degrees upon arrival in parking slot.

3. Disappear: Lid seals tightly, lifts up 2m, and scales to 0 with particle pop.

Cardboard Box Item

Transport Item
  • ● Cardboard box for transporting cargo items.
  • ● 8 Color-coded packaging tiers matching container colors.
  • ● Distinct 3D mesh model & stamp icon per item type.
ANIMATION SPEC:

1. Unpack Flight: Eject upwards from container onto conveyor belt (Bezier arc 0.25s).

2. Conveyor Scroll: Linear translation along roller track with rotation pulse.

3. Pack In: Fly from belt into container slot with squish/stretch bounce.

Roller Conveyor Track

Environment
  • ● Dark industrial roller belt with bright directional arrows.
  • ● Stores loose cardboard box items extracted from containers.
ANIMATION SPEC:

1. Belt Scroll: UV texture offset animation matching current conveyor speed (1x / 2x).

2. Roller Spin: Continuous 360-degree rotation of individual roller cylinders.

Spare Wood Container

Special Box
  • ● Stores items without color matching constraints.
  • ● Distinct outer wooden texture to avoid container confusion.
ANIMATION SPEC:

1. Unpack & Shatter: Lid pops open, items fly out, wooden planks break apart with dust cloud particle effect.

2. Special Puzzle Element Objects

Rainbow Container Object

Special Element
  • ● Covered in a colorful rainbow wrapper hiding actual color.
  • ● Reveals true target color & items once completely unblocked.
ANIMATION SPEC:

1. Remove Cover: Rainbow wrapper unravels/peels away with glowing particle effect to reveal actual container color.

Ship Door Spawner Portal

Spawner
  • ● Designed as an open ship bulkhead door integral to ship hull.
  • ● Holds container queue and decrements counter UI per spawn.
ANIMATION SPEC:

1. Spawn Box: Bulkhead door slides open, internal hydraulic arm pushes new container into exit slot when previous box dispatches.

Frozen Ice Container

Ice Element
  • ● Container trapped in ice shell with overlay counter badge.
  • ● Non-interactable until counter hits 0 and ice shatters.
ANIMATION SPEC:

1. Ice Break: Outer ice block cracks dynamically on each countdown, then explodes outward into frost particles when free.

Locked Parking Slot

Blocked Slot
  • ● Features construction warning stripes, barrier fence, and counter.
  • ● Unlocks into empty parking slot when counter reaches 0.
ANIMATION SPEC:

1. Remove Block: Hazard tape snaps, safety barrier drops down out of frame, revealing standard green parking slot glow.

3. Booster Visual Objects & FX

Wood Container Booster

Wooden box icon with items vacuuming inside and a prominent '+' badge indicating extra item storage.

ANIMATION SPEC:

Wood Container Appear: Spawn point bursts with industrial dust/smoke particle cloud, followed by wood container drop-in landing.

Magnet Booster Visual

Red Horseshoe magnet emitting electromagnetic arc rays toward matching color cargo items.

ANIMATION SPEC:

Magnet Pulling: A magnet appear beside the target container; all matching color items accelerate along curved magnetic trails into container.

Crane Grabber (Remove)

Industrial gantry crane claw grabbing a container and loading matching cardboard items.

ANIMATION SPEC:

Swap Item: Selected container fly up hovers overhead the container stack, and performs two-way flying item swap with source containers.
